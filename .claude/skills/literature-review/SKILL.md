# 文献综述生成 Skill

按四部分推进一篇文献综述:研究背景与目的 → 文献梳理与分析 → 研究现状总结与评述 → 参考文献。
核心是**前期对齐充分、文献真实可核验**:开场把题目、文献来源、输出格式一次性问清,文献清单经用户核验,
然后一口气写完整篇初稿再交付,不再一段段停下来确认。

## 触发条件

- 用户要写文献综述 / 国内外研究现状
- 关键词:文献综述、写综述、literature review、帮我写文献综述、国内外研究现状

## 三条铁律

1. **文献必须真**:写入正文的每一篇文献都要有可核验来源。用户自己粘的照用;AI 搜的必须带出处链接、先给用户核对,禁止凭记忆编造标题、作者、年份。
2. **前期对齐、一次成稿**:干预集中在动笔之前——开场对齐、文献清单核验。这些过了之后,四部分连着一次性写完整篇,不再逐段停下来问用户。
3. **先写主体**:四部分里先写"文献梳理与分析",它定了全篇口径,之后回填背景、现状、参考文献才接得上。这只是内部撰写顺序,不是分批交付。

## 交互总则:所有干预点一律走 AskUserQuestion

这个 skill 的人工干预**必须用 AskUserQuestion 工具发起**,不要用普通文字提问代替。凡是需要用户拍板、确认、选择的地方,都调 AskUserQuestion,把选项列出来让用户点。下面每个 Phase 标了 🟢**[AskUserQuestion]** 的地方,都是强制调用点,不许跳过、不许改成"你觉得呢?"这类开放式文字问法。

干预点全部集中在动笔之前,一共这几处强制 AskUserQuestion:
1. Phase 0 开场三连问(题目、文献来源、输出格式)
2. Phase 1 文献清单核验(列出候选后,让用户确认/删改)
3. LaTeX 模板来源确认(找到模板后让用户确认用不用)

**这些前期干预过了之后,Phase 2 撰写正文阶段不再调用 AskUserQuestion**:四部分连着一次性写完,直接输出完整初稿,不逐段停下来问用户可不可行。

## 工作流程

### Phase 0:开场对齐 🟢[AskUserQuestion]

**调用一次 AskUserQuestion,把下面三个问题一起问**(题目那题用户多半会填"其他"自由输入):

- **论文题目/研究方向**:选项给"我在下方输入题目"之类,主要靠用户自填。
- **文献来源**:选项 = 「我自己粘贴现成文献清单」/「让 AI 联网搜索文献」。
- **输出格式**:选项 = 「直接对话输出」/「Markdown 文件」/「Word」/「LaTeX」。

若用户选了 LaTeX,**再补一次 AskUserQuestion 或在同批问题里追问目标期刊/会议名称**(用于 LaTeX 流程搜模板)。信息不全绝不自己假设,缺哪问哪。

### Phase 1:备齐真文献

按 Phase 0 选的来源分两条路。

**A. 用户自己粘贴**
让用户把中英文文献清单贴进来。提醒他导出时选信息最全的格式(标题、作者、年份、摘要都带上),
字段越全,后面正文越不容易出错。

**B. AI 联网搜索(防编造是重点)**
- 用 WebSearch 按题目关键词检索,中文题目搜中文、英文题目搜英文;时间圈定近五年。
- 每一篇候选文献都要能追到真实出处(期刊/数据库/DOI/可访问链接),必要时用 WebFetch 打开核对标题、作者、年份是否属实。
- 追不到出处、或信息对不上的,一律丢弃,绝不写进清单充数。
- 数量凑够一批(二十篇上下、中英各半比较够用,依题目和用户要求定)。
- 🟢**[AskUserQuestion]** 先把核验过的候选清单(编号、标题、作者、年份、出处链接)完整列在正文里给用户看,**然后调用 AskUserQuestion** 问用户是否采用这份清单,选项 = 「这份清单可以,开始写」/「我要删掉或替换某几篇(在备注里说明)」/「重新搜/我改用自己粘贴」。用户确认前不写正文。

无论哪条路,进入 Phase 2 前,手里都要有一份用户经 AskUserQuestion 认可的真实文献清单。

### Phase 2:一次性写完整篇正文(不再逐段确认)

前期对齐和文献清单都过了,这一阶段**连着把四部分一口气写完,不再调用 AskUserQuestion,不逐段停下来问用户**。

**动笔前先 Read `references/prompts.md`**,把四部分的提示词正文和《行文要求》一次性读进上下文再写——不要凭记忆写,这是防止长流程里遗忘和文风漂移的关键动作。

内部撰写顺序仍按下面来(先写主体定口径),但这是你自己写作的顺序,不是分批交给用户:
**① 文献梳理与分析(主体,先写)→ ② 研究背景与目的 → ③ 研究现状总结与评述 → ④ 参考文献。**

四部分都写完后,拿《行文要求》整体对照自查一遍(有没有冒出列表体、排比、"综上所述"、半角标点、中英文之间空格等),不合格自己先修好,然后**把完整的一篇初稿一次性输出/交付**(按 Phase 3 的格式)。

### Phase 3:按格式交付完整初稿

把 Phase 2 写好的整篇按 Phase 0 选的格式一次性落地,并明确告诉用户"这是完整初稿,自己跑一遍看效果,哪里要改再一起改":

- **对话**:直接输出。
- **Markdown**:用 Write 写成 .md 文件。
- **Word**:用 Bash 调 pandoc 或 python-docx 把 Markdown 转 .docx;没有工具就先给 Markdown 并说明。
- **LaTeX**:见下方专门流程。

## LaTeX 输出流程

用户选 LaTeX 时:

1. **搜真实期刊模板**:用 WebSearch/WebFetch 找目标期刊或会议的官方 LaTeX 模板(官网、Overleaf 官方模板库、出版社页面)。
2. **给用户核验** 🟢**[AskUserQuestion]**:把找到的模板来源(名称+链接)列出来,调用 AskUserQuestion 让用户确认,选项 = 「用这个官方模板」/「都不对,用通用模板」/「我另外提供模板链接」。和搜文献一个逻辑——不确定、疑似非官方/山寨的不用。
3. **降级兜底**:确实找不到官方模板,就用通用 `article` 类(带 ctex 支持中文)套,并**明确告诉用户"没找到该期刊官方模板,当前用的是通用模板"**,不要伪造成官方模板。
4. **始终产出可编译的 .tex**:把正文和参考文献填进模板,保证结构完整能编译。
5. 交付时说明这是初稿,让用户自己套进期刊环境跑一遍看效果。
