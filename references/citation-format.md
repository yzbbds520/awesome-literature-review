# 参考文献格式细则(GB/T 7714-2015)

写参考文献那一部分之前先 Read 本文件。默认用国标 GB/T 7714-2015 顺序编码制;
用户在 Phase 0 指定了别的规范(APA / MLA / 期刊自有格式)就按用户确认的来,但同一篇稿子里不许混用。

**只列 Phase 1 已确认清单里的文献,不得新增条目。**

---

## 标点约定(先看这条)

参考文献条目内部**一律用半角标点,标点后空一格**,中文条目和英文条目同一套。国标示例本身就是这么排的,
不要因为是中文文献就换成全角。

- 逗号 `, ` 分隔作者和年卷期;句点 `. ` 分隔各字段;冒号 `: ` 引出页码;分号 `; ` 用于并列项。
- 卷期用半角圆括号,`46(3)`,括号前不空格。
- 中文题名或刊名内部原有的书名号《》、顿号、间隔号照原样留着,那是题名的一部分,不是分隔标点。
- 一个条目里不许半角全角混用;中文条目之间、英文条目之间也要各自统一。

**《行文要求》里"全角中文标点"那一条只管正文,不管参考文献。** 两处规则不一样,别互相套。

---

## 通用规则

- 顺序编码制:按正文中首次出现的顺序编号,`[1] [2] [3]` 依次排,与正文标注一一对应。
- 每条必须带**文献类型标识**,放在题名后的方括号里:
  期刊 `[J]`、专著 `[M]`、学位论文 `[D]`、会议论文集 `[C]`、报告 `[R]`、标准 `[S]`、专利 `[P]`、电子资源 `[EB/OL]`。
- 作者三名以内全部列出,用逗号分隔;**超过三名列前三名,后加"等"**(英文文献加 "et al.")。
- 中文作者姓名全写,不缩写。英文作者姓在前名在后,名只留首字母且不加点,如 `Page M J`。
- 各条目末尾加句点。DOI 后不加句点。
- 页码用起止页,中间用短横线,如 `45-58`;单页直接写页码。
- 缺项处理:确实查不到的字段直接省略该字段及其前置标点,**不要写"不详"、不要编**。

---

## 各类型格式

**期刊论文 `[J]`**

```
[序号] 主要责任者. 题名[J]. 刊名, 出版年, 卷(期): 起止页码.
```
- 中文示例:`[1] 张伟, 李明, 王芳, 等. 深度学习在医学影像中的应用[J]. 计算机学报, 2023, 46(3): 512-528.`
- 英文示例:`[2] Page M J, McKenzie J E, Bossuyt P M, et al. The PRISMA 2020 statement[J]. BMJ, 2021, 372: n71.`
- 卷期都有写 `卷(期)`;只有期写 `(期)`;两者都无则省略,直接接页码。

**专著 `[M]`**

```
[序号] 主要责任者. 书名[M]. 版本(第一版不写). 出版地: 出版者, 出版年: 起止页码.
```
`[3] 周志华. 机器学习[M]. 北京: 清华大学出版社, 2016: 73-95.`

**专著中的析出文献(章节)`[M]`**

```
[序号] 析出文献主要责任者. 析出文献题名[M]//专著主要责任者. 专著题名. 出版地: 出版者, 出版年: 析出文献起止页码.
```

**学位论文 `[D]`**

```
[序号] 主要责任者. 题名[D]. 保存地: 保存者, 年份.
```
`[4] 陈静. 面向小样本的图像分类方法研究[D]. 杭州: 浙江大学, 2022.`

**会议论文 `[C]`**

```
[序号] 主要责任者. 题名[C]//会议论文集编者. 论文集名. 出版地: 出版者, 出版年: 起止页码.
```

**电子资源 `[EB/OL]`**

```
[序号] 主要责任者. 题名[EB/OL]. (更新日期)[引用日期]. 获取路径.
```
`[5] 中国互联网络信息中心. 第53次中国互联网络发展状况统计报告[EB/OL]. (2024-03-22)[2026-07-26]. https://www.cnnic.net.cn/....`
- 日期格式 `YYYY-MM-DD`。引用日期就是你实际访问那天。

**带 DOI 的条目**

在末尾追加,格式 `DOI: 10.xxxx/xxxxx`,**后面不加句点**。
用户说不要 DOI 就整体删掉,不要留半截。

---

## 正文标注规则

- 标注放在**引用内容处**,不是无脑挂句尾。上标或方括号按用户/期刊要求,默认方括号 `[1]`。
- 行文中要点作者名:`张伟[1]提出……`、`Page 等[2]发现……`,不要只有一个孤零零的编号。
- 连续多篇合并:`[1-3]`;不连续多篇:`[1,4,7]`。
- 同一篇文献在正文中多次出现,**沿用第一次的编号**,不重新编。

---

## 交付前自查

- [ ] 编号与正文首次出现顺序一致,无跳号、无重号、无断号
- [ ] 每条都有文献类型标识 `[J]/[M]/[D]/[C]/[EB/OL]` 等
- [ ] 超过三名作者的已用"等"截断,没有一路列到底
- [ ] 期刊条目年卷期页码齐全(确实没有的已省略而非编造)
- [ ] 电子资源带访问日期和可达链接
- [ ] DOI 后没有句点;不要 DOI 的已整体删净
- [ ] 条目数与已确认清单完全一致,一篇没多一篇没少
- [ ] **条目内标点全部半角、标点后空一格,中英文条目同一套,没有混用全角**
- [ ] 中文题名里原有的《》和顿号保留了,没被当成分隔标点改掉
