# 内容完整性清单

四部分写完、交付之前 Read 本文件,逐项对照全文核一遍。
这份清单管的是**该写的写全了没有**,和《行文要求》分工不同——后者管文风。
不合格的自己先补齐修好,再交付。

标注 `[可选]` 的项目按用户需求和题目性质定,不适用就跳过,但要在交付说明里讲一句。

---

## 一、文献梳理与分析(主体)

- [ ] 已确认清单里的文献**全部用上**,一篇没漏
- [ ] 正文按 `[1][2]` 依次标序号,编号连续到最后一篇,无跳号重号
- [ ] 行文中点出了作者名,不是只在句尾挂编号
- [ ] 组织方式明确(按主题/按技术路线/按研究方法),不是时间顺序流水账
- [ ] 每段前有小标题,小标题之间是并列关系、不交叉重叠
- [ ] 每篇文献都讲了它**做了什么、得到什么结论**,不是只报个标题
- [ ] 同一主题下的文献之间有对比或递进关系,不是一篇一段互不相干地堆
- [ ] 各主题分支下的文献数量没有严重失衡(某个主题只挂一篇要么合并要么补)

## 二、研究背景与目的

- [ ] 背景讲清了:选题为什么重要、现在到了什么阶段、问题怎么提出来的
- [ ] 目的讲清了:这篇综述要弄清的核心问题、对后续研究的作用
- [ ] 范围讲清了:年份跨度、纳入的文献类型、限定的学科方向或对象范围
- [ ] 范围表述与实际清单**对得上**(说了近五年就不能引十年前的,除了公认奠基性文献)

## 三、研究现状总结与评述

- [ ] 说清了领域整体走到哪一步
- [ ] 指出了现有研究的短板或空白,且**具体**(不是"研究还不够深入"这类空话)
- [ ] 指出的空白能在前面的文献梳理里找到依据,不是凭空断言
- [ ] 给了未来方向,且和前面指出的空白对应上
- [ ] 评述里没有出现文献梳理部分没提过的新文献

## 四、参考文献

- [ ] 已按 `references/citation-format.md` 的细则核过(默认 GB/T 7714-2015)
- [ ] 条目数与已确认清单完全一致,一篇没多一篇没少
- [ ] 编号顺序与正文首次出现顺序一致

## 五、全局

- [ ] 全文没有已确认清单之外的文献,**没有任何编造的标题、作者、年份**
- [ ] 已按《行文要求》自查过文风(列表体、排比、"综上所述"、半角标点、中英文间空格)
- [ ] 题目、范围、组织方式三者口径一致,前后不打架
- [ ] 篇幅符合用户要求(用户提了字数就核一遍)
- [ ] `[可选]` 文献特征汇总表:文献超过十篇时值得给一张(作者年份/研究方法/研究对象/核心结论)
- [ ] `[可选]` 配图:按 `references/diagrams.md` 生成,出图后逐框核对过文字和编号
- [ ] 交付说明里讲明了这是初稿、可选项哪些没做、待用户补的信息有哪些
