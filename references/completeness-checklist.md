# 证据核查 + 内容完整性清单

四部分写完、交付之前 Read 本文件,逐项对照全文核一遍。
这份清单管两件事:**该有依据的有没有依据**、**该写的写全了没有**。文风归《行文要求》管,分工不同。
不合格的自己先补齐修好,再交付。

标注 `[可选]` 的项目按用户需求和题目性质定,不适用就跳过,但要在交付说明里讲一句。

---

## 零、证据核查(先过这一关,最要紧)

- [ ] 正文里每一处方法名、模型名、数据集、指标、数值、百分比,都能对回它所引文献的**A 级原文**
- [ ] 标为 B 级(仅题录)的文献,正文里只写到主题和方向层面,**没有出现原文没读到的具体做法和数字**
- [ ] 没有出现"提升了 X%""准确率达到 Y"这类没有原文出处的数字
- [ ] 对文献方法学的评价,只针对读到过方法描述的那几篇,没有隔着题目评质量
- [ ] 拿不准是不是原文里的细节,已经删掉而不是靠语感留着

**这一关不过就别往下走。** 参考文献列表全真、正文转述失实,比整条假引用更难被发现,危害更大。

---

## 一、文献梳理与分析(主体)

- [ ] 已确认清单里的文献**全部用上**,一篇没漏
- [ ] 正文按 `[1][2]` 依次标序号,编号连续到最后一篇,无跳号重号
- [ ] 行文中点出了作者名,不是只在句尾挂编号
- [ ] 组织方式明确(按主题/按技术路线/按研究方法),不是时间顺序流水账
- [ ] 每段前有小标题,小标题之间是并列关系、不交叉重叠
- [ ] 每篇文献都讲了它**做了什么、得到什么结论**(A 级)或**切入的问题与路线**(B 级),不是只报个标题
- [ ] 同一主题下的文献之间有对比或递进关系,不是一篇一段互不相干地堆
- [ ] **至少写出一处不同研究之间的结论分歧,并给了可能的原因**(样本、场景、指标口径、方法本身)
- [ ] 各主题分支下的文献数量没有严重失衡(某个主题只挂一篇要么合并要么补)
- [ ] 每个分支收尾点了这条路线目前卡在哪,给后面的评述留了线索

## 二、研究背景与目的

- [ ] 背景讲清了:选题为什么重要、现在到了什么阶段、问题怎么提出来的
- [ ] 目的讲清了:这篇综述要弄清的核心问题、对后续研究的作用
- [ ] 范围讲清了:年份跨度、纳入的文献类型、限定的学科方向或对象范围
- [ ] **文献是怎么找的也交代了**:用了哪些库或渠道、大致检索词、纳入排除的把握(走 C 路的用检索记录)
- [ ] 范围表述与实际清单**对得上**(说了近五年就不能引十年前的,除了公认奠基性文献)

## 三、研究现状总结与评述

- [ ] 说清了领域整体走到哪一步:共识、主流路线、公认难点
- [ ] **写出了同一问题上不同研究的结论分歧**,并分析了分歧可能来自哪里(样本、场景、指标、方法)
- [ ] 指出了现有研究在方法学上的共性局限,且**具体**(不是"研究还不够深入"这类空话),且只评价读到过方法描述的文献
- [ ] **研究空白落到了具体的三件事上**:哪个对象/场景没人做、哪种方法没用到这个问题上、哪个变量/环节被忽视
- [ ] **解释了空白为什么还在**:数据获取、伦理限制、算力成本、缺乏统一标准、学科壁垒——说出原因读者才判断值不值得做
- [ ] 指出的空白能在前面的文献梳理里找到依据,不是凭空断言
- [ ] 未来方向与前面指出的空白**逐条对应**,没有另起新话题
- [ ] 如果是学位论文研究现状,最后一段把空白接回了作者自己的研究问题
- [ ] 评述里没有出现文献梳理部分没提过的新文献

## 四、参考文献

- [ ] 已按 `references/citation-format.md` 的细则核过(默认 GB/T 7714-2015)
- [ ] **条目内标点全部半角、标点后空一格**,无全角混用
- [ ] 条目数与已确认清单完全一致,一篇没多一篇没少
- [ ] 编号顺序与正文首次出现顺序一致

## 五、全局

- [ ] 全文没有已确认清单之外的文献,**没有任何编造的标题、作者、年份**
- [ ] 已按《行文要求》自查过文风(列表体、排比、"综上所述"、中英文间空格)
- [ ] **已过证据核查:正文里没有 B 级文献的具体方法名/数字**
- [ ] 题目、范围、组织方式三者口径一致,前后不打架
- [ ] 篇幅符合用户要求(用户提了字数就核一遍)
- [ ] `[可选]` 文献特征汇总表:文献超过十篇时值得给一张(作者年份/研究方法/研究对象/核心结论,B 级文献"核心结论"那列留空或标"摘要未获取")
- [ ] `[可选]` 配图:按 `references/diagrams.md` 生成,出图后逐框核对过文字和编号
- [ ] 交付说明里讲明了:这是初稿;哪几篇是 B 级证据(正文只写到主题层面);检索局限与建议补充的数据库;可选项哪些没做
